Вы работаете в службе поддержки интернет-магазина музыки. Каждый тикет ниже — небольшая рабочая ситуация, и каждый тикет — это один метод, который нужно дописать с помощью цикла for.

- Дано: параметры, которые получает метод.
- Вернуть: что метод должен вернуть (или что напечатать).
- Примеры: вызовы и ожидаемые результаты. Запустите их в main, чтобы проверить себя.
---
Тикет 1. Нумерация для ежедневного отчёта
Руководитель поддержки хочет пронумерованный список первых 10 тикетов для ежедневного отчёта.
Напечатайте числа от 1 до 10, каждое на отдельной строке.

- Дано: ничего, у метода нет параметров (скобки пустые).
- Вернуть: ничего, метод печатает в консоль.

Ожидаемый вывод (10 строк):

  1
  2
  3
  ...
  10

Подсказка: Начните с `i = 1`, повторяйте пока `i <= 10`, прибавляйте 1 через `i++`.

Тикет 2. Операторы на чётных линиях
У поддержки есть телефонные линии 1..20, но сегодня оператор дежурит только на чётных.
Напечатайте номера этих линий: 2, 4, 6 ... 20, каждый на отдельной строке.

- Дано: ничего, у метода нет параметров (скобки пустые).
- Вернуть: ничего, метод печатает в консоль.

Ожидаемый вывод (10 строк):

  2
  4
  6
  ...
  20

Подсказка: Начните с `i = 2` и шагайте по 2: `i += 2`.

Тикет 3. Обратный отсчёт до распродажи
Большая распродажа начнётся через 10 секунд, и баннер показывает обратный отсчёт.
Напечатайте числа от 10 до 1, каждое на отдельной строке.

- Дано: ничего, у метода нет параметров (скобки пустые).
- Вернуть: ничего, метод печатает в консоль.

Ожидаемый вывод (10 строк):

  10
  9
  8
  ...
  1

Подсказка: Начните с `i = 10` и идите вниз через `i--`.

Тикет 4. Продано треков за неделю
Каждый день магазин продаёт больше: в день 1 — 1 трек, в день 2 — 2 трека, в день 3 — 3 трека
и так далее. Сколько треков продано всего за первые n дней?
Иначе говоря, посчитайте 1 + 2 + ... + n.

- Дано: n — количество дней (n >= 1).
- Вернуть: общее число треков.

Примеры:
- task4(5) -> 15 (1 + 2 + 3 + 4 + 5)
- task4(1) -> 1
- task4(10) -> 55

Подсказка: Заведите переменную `sum` до цикла и делайте `sum += i` на каждом шаге.

Тикет 5. Перемешивание плейлиста
Клиент спрашивает: «Сколькими разными способами можно упорядочить n треков?»
Ответ — n! (факториал n) = 1 * 2 * 3 * ... * n. Он растёт очень быстро, поэтому метод возвращает long.

- Дано: n — количество треков (n >= 0).
- Вернуть: n! По определению 0! равен 1.

Примеры:
- task5(3) -> 6 (1 * 2 * 3)
- task5(5) -> 120
- task5(0) -> 1

Подсказка: Начните `result` с `1` (не с `0`) и делайте `result *= i` на каждом шаге.

Тикет 6. Самый большой счёт
Менеджер даёт вам суммы сегодняшних счетов. Пройдите по массиву и найдите самую большую
сумму. Не сортируйте массив.

- Дано: arr — суммы счетов (хотя бы один элемент).
- Вернуть: самое большое число в массиве.

Примеры:
- [40, 250, 90] -> 250
- [7] -> 7
- [-5, -2, -9] -> -2

Подсказка: Возьмите `arr[0]` как текущий `max` и сравнивайте с ним каждый следующий элемент.

Тикет 7. Прибыльные дни
В массиве лежит прибыль за каждый день месяца. Положительное число — прибыль,
отрицательное — убыток, 0 — магазин ничего не заработал.
Сколько было дней, когда прибыль больше 0?

- Дано: arr — прибыль за каждый день.
- Вернуть: количество элементов больше 0.

Примеры:
- [100, -20, 0, 50] -> 2
- [-1, -2] -> 0

Подсказка: Счётчик `count` начинается с `0` и растёт на 1 (`count++`), когда элемент `> 0`.

Тикет 8. Промокод задом наперёд
Клиент набрал промокод справа налево. Восстановите его: соберите новый текст из тех же
символов в обратном порядке. Не используйте StringBuilder.reverse().

- Дано: s — текст, который набрал клиент.
- Вернуть: тот же текст задом наперёд.

Примеры:
- task8("abc") -> "cba"
- task8("ELAS") -> "SALE"
- task8("") -> ""

Подсказка: Идите от последнего индекса `s.length() - 1` вниз до `0` и добавляйте `s.charAt(i)`.

Тикет 9. Гласные в названии песни
Отдел маркетинга анализирует названия песен. Посчитайте гласные a, e, i, o, u в названии.
Заглавные буквы тоже считаются: "A" — гласная, как и "a".

- Дано: s — название песни.
- Вернуть: количество гласных в нём.

Примеры:
- task9("Hello World") -> 3 (e, o, o)
- task9("ABBA") -> 2
- task9("Rhythm") -> 0

Подсказка: Сначала переведите название в нижний регистр (`toLowerCase()`), потом проверьте каждый символ по `"aeiou"`.

Тикет 10. Счастливый номер тикета
Клиент получает бонус, если номер его тикета — простое число.
Простое число больше 1 и делится только на 1 и на само себя.
Проверьте все возможные делители от 2 до n - 1.

- Дано: n — номер тикета.
- Вернуть: true, если n простое, иначе false.

Примеры:
- task10(7) -> true
- task10(2) -> true
- task10(9) -> false (9 = 3 * 3)
- task10(1) -> false

Подсказка: Числа меньше 2 не простые. Если `n` делится на какое-то `i` от 2 (`n % i == 0`), оно не простое.

Тикет 11. Баннер для страницы поддержки
Дизайнер просит лесенку из звёздочек высотой n строк: в строке 1 одна звёздочка,
в строке 2 — две и так далее, в строке n — n звёздочек.
Понадобятся два цикла: один по строкам и второй внутри него — по звёздочкам строки.

- Дано: n — количество строк.
- Вернуть: ничего, метод печатает в консоль.

Ожидаемый вывод для n = 3:

  *
  **
  ***

Подсказка: Внутренний цикл выполняется `i` раз и печатает `"*"` через `print`; после него вызовите `println()`.

Тикет 12. Метки тикетов
Служба поддержки печатает метки всех тикетов 1..n, каждую на отдельной строке.
Метка зависит от номера тикета:

- делится на 3 и на 5: FizzBuzz (срочный тикет)
- делится только на 3: Fizz (тикет по оплате)
- делится только на 5: Buzz (тикет по доставке)
- всё остальное: сам номер

- Дано: n — номер последнего тикета.
- Вернуть: ничего, метод печатает в консоль.

Ожидаемый вывод для n = 15:

  1
  2
  Fizz
  4
  Buzz
  Fizz
  7
  ...
  14
  FizzBuzz

Подсказка: Цикл от 1 до `n`; внутри цепочка `if` / `else if`, и первой проверяйте `% 15`.
