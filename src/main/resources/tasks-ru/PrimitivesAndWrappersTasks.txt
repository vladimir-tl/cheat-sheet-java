Вы работаете в службе поддержки интернет-магазина музыки. Каждый тикет ниже — небольшая рабочая ситуация, и каждый тикет — это один метод, который нужно дописать.

- Дано: параметры, которые получает метод.
- Вернуть: что метод должен вернуть.
- Примеры: вызовы и ожидаемые результаты. Запустите их в main, чтобы проверить себя.
---
Тикет 1. Цена из формы
Форма администратора присылает цену альбома текстом, например "250". Чтобы считать с ней,
программе нужно число. Текст всегда — правильное целое число.

- Дано: text — цена в виде текста.
- Вернуть: ту же цену как int.

Примеры:
- task1("250") -> 250
- task1("-15") -> -15

Подсказка: В классе `Integer` есть метод, который разбирает текст в `int`.

Тикет 2. Скидка из формы
Скидка приходит текстом и может быть с дробной частью, например "12.5".
Текст всегда — правильное число с точкой.

- Дано: text — скидка в виде текста.
- Вернуть: ту же скидку как double.

Примеры:
- task2("12.5") -> 12.5
- task2("7") -> 7.0

Подсказка: В классе `Double` есть похожий метод `parse...`.

Тикет 3. Номер заказа в письме
Шаблон письма вставляет только текст, а номер заказа — это int. Превратите число в текст.

- Дано: orderId — номер заказа.
- Вернуть: тот же номер в виде String.

Примеры:
- task3(42) -> "42"
- task3(1005) -> "1005"

Подсказка: `String.valueOf` превращает в текст почти что угодно.

Тикет 4. Средняя оценка
Альбом получил несколько оценок. Известны их общая сумма sum и количество count.
Среднее — это sum / count, но дробная часть должна сохраниться.
Осторожно: в Java int / int отбрасывает дробную часть, 9 / 2 даёт 4.

- Дано: sum — сумма оценок; count — количество оценок (count > 0).
- Вернуть: среднее как double, с дробной частью.

Примеры:
- task4(9, 2) -> 4.5 (а не 4.0)
- task4(10, 4) -> 2.5
- task4(6, 3) -> 2.0

Подсказка: Приведите одно из чисел к `double` ДО деления: `(double) sum`.
---
Тикет 5. Целые евро
Принтер чеков печатает только целые евро. Отбросьте центы: просто отрежьте дробную часть,
не округляйте.

- Дано: price — цена с центами.
- Вернуть: целую часть цены как int.

Примеры:
- task5(19.99) -> 19 (а не 20)
- task5(5.0) -> 5
- task5(0.5) -> 0

Подсказка: Приведение `(int)` просто отбрасывает дробную часть.

Тикет 6. Прослушивания за весь период
Хит слушают playsPerDay раз в день в течение days дней. Посчитайте общее число прослушиваний:
playsPerDay * days. Результат может быть больше самого большого int (около 2,1 миллиарда),
поэтому метод возвращает long, и ответ должен быть правильным даже для больших чисел.

- Дано: playsPerDay — прослушиваний в день; days — количество дней.
- Вернуть: общее число прослушиваний как long.

Примеры:
- task6(100, 30) -> 3000
- task6(2_000_000, 3_000) -> 6_000_000_000 (а не странное отрицательное или маленькое число)

Подсказка: Приведите один из множителей к `long` ДО умножения, иначе сначала переполнится `int`.
---
Тикет 7. Неизвестный бонус
Бонусные баллы клиента приходят из другой системы как Integer. Если та система не знает
баллов, она присылает null. Считайте неизвестные баллы равными 0.

- Дано: bonus — баллы или null.
- Вернуть: баллы как int или 0, если bonus равен null. Программа не должна падать.

Примеры:
- task7(150) -> 150
- task7(null) -> 0

Подсказка: Сначала проверьте `bonus == null`; только потом превращайте его в `int`.
---
Тикет 8. Тот же клиент?
В двух заказах id клиентов a и b хранятся как объекты Integer (никогда не null).
Проверьте, принадлежат ли оба заказа одному клиенту, то есть равны ли два id.
Убедитесь, что это работает и для больших id: для 1000 и 1000 ответ должен быть true.

- Дано: a и b — два id клиентов.
- Вернуть: true, если id равны, иначе false.

Примеры:
- task8(1000, 1000) -> true
- task8(5, 5) -> true
- task8(5, 7) -> false

Подсказка: `==` на `Integer` сравнивает объекты. Значения сравнивайте через `equals`.
