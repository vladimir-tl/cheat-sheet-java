Вы работаете в службе поддержки интернет-магазина музыки. Каждый тикет ниже — небольшая рабочая ситуация, и каждый тикет — это один метод, который нужно дописать.

- Дано: параметры, которые получает метод.
- Вернуть: что метод должен вернуть (или как изменить массив).
- Примеры: входные данные и ожидаемые результаты. Запустите их в main, чтобы проверить себя.
---
Тикет 1. Топ-5 чарта
В недельном чарте пять мест. Подготовьте их: создайте массив int, в котором лежат
числа 1, 2, 3, 4, 5 в этом порядке.

- Дано: ничего, у метода нет параметров (скобки пустые).
- Вернуть: новый массив.

Пример:
- task1() -> [1, 2, 3, 4, 5]

Подсказка: Массив с известными значениями можно записать сразу в фигурных скобках: `new int[]{...}`.
---
Тикет 2. Пустая схема зала
На онлайн-концерте n мест. Создайте схему зала: массив int из n ячеек.
Каждая ячейка должна быть 0 — это значит «свободно» (новый массив int и так заполнен нулями).

- Дано: n — количество мест (n >= 0).
- Вернуть: новый массив длины n.

Примеры:
- task2(3) -> [0, 0, 0]
- task2(0) -> []

Подсказка: `new int[размер]` создаёт массив нужного размера; в каждой ячейке уже лежит `0`.
---
Тикет 3. Кто первый?
В массиве лежат номера клиентов, ожидающих в очереди; первый — в начале.
Верните номер клиента, который стоит первым.

- Дано: arr — очередь (хотя бы один элемент).
- Вернуть: первый элемент массива.

Примеры:
- [17, 4, 9] -> 17
- [5] -> 5

Подсказка: Индексы начинаются с `0`.
---
Тикет 4. Последний заказ
В массиве лежат номера заказов в порядке поступления, поэтому последний — в конце.
Метод должен работать для массива любой длины.

- Дано: arr — номера заказов (хотя бы один элемент).
- Вернуть: последний элемент массива.

Примеры:
- [101, 102, 103] -> 103
- [42] -> 42

Подсказка: Последний индекс на единицу меньше длины: `arr.length - 1`.
---
Тикет 5. Акционная цена
В первой ячейке массива цен лежит цена альбома дня. Сегодня на него акция:
положите 100 в первую ячейку. Остальные ячейки не трогайте.

- Дано: arr — цены (хотя бы один элемент).
- Вернуть: ничего. Измените полученный массив.

Пример:
- массив был [250, 80, 40], после вызова он [100, 80, 40]

Подсказка: В ячейку пишут так же, как читают, только слева от `=`.
---
Тикет 6. Длина очереди
Сколько клиентов в очереди? Это столько, сколько ячеек в массиве.

- Дано: arr — очередь.
- Вернуть: длину массива.

Примеры:
- [5, 8, 1] -> 3
- [] -> 0

Подсказка: У массива есть поле `length`, без скобок.
---
Тикет 7. Пришёл новый заказ
В массиве лежат номера заказов. Пришёл новый заказ с номером value.
Массив не может вырасти, поэтому создайте НОВЫЙ массив на одну ячейку длиннее:
скопируйте в него старые заказы и положите value в последнюю ячейку. Старый массив должен остаться прежним.

- Дано: arr — старые заказы; value — номер нового заказа.
- Вернуть: новый массив.

Примеры:
- arr [1, 2, 3], value 4 -> [1, 2, 3, 4]
- arr [], value 7 -> [7]

Подсказка: Массив не может вырасти. `Arrays.copyOf(arr, новаяДлина)` делает копию побольше; потом заполните её последнюю ячейку.
---
Тикет 8. Отчёт для менеджера
Менеджер хочет видеть номера заказов читаемым текстом: в квадратных скобках,
через запятую и пробел.

- Дано: arr — номера заказов.
- Вернуть: массив в виде текста.

Примеры:
- [1, 2, 3] -> "[1, 2, 3]"
- [] -> "[]"

Подсказка: В классе `Arrays` есть готовый метод, который превращает массив в текст вида `[1, 2, 3]`.
---
Тикет 9. Выручка за день
В массиве лежат суммы сегодняшних заказов. Сложите их все.

- Дано: arr — суммы заказов.
- Вернуть: сумму всех элементов или 0 для пустого массива.

Примеры:
- [10, 25, 5] -> 40
- [] -> 0

Подсказка: Начните с `sum = 0` и прибавьте к ней каждый элемент в цикле for-each: `sum += x`.
---
Тикет 10. Надёжная резервная копия
Перед рискованной правкой вы делаете резервную копию массива цен. Копия должна быть
независимой: новый массив с теми же числами. Если потом кто-то изменит копию, оригинал
не должен измениться. Внимание: return arr — это не копия, оба имени будут указывать на один и тот же массив.

- Дано: arr — цены.
- Вернуть: новый массив с теми же элементами.

Пример:
- [5, 10, 15] -> [5, 10, 15]; после copy[0] = 99 оригинал по-прежнему [5, 10, 15]

Подсказка: `Arrays.copyOf` с той же длиной создаёт новый, независимый массив.
