Вы работаете в службе поддержки интернет-магазина музыки. Каждый тикет ниже — это небольшая рабочая ситуация и один метод, который нужно создать. В тикете сказано, как называется метод и какие у него параметры. Заготовка показана под условием (в WarmupListTasks.java она уже есть), так что остаётся написать тело метода.
Понадобятся всего четыре операции: size, get, add и reverse.

Как читать тикет:
- Что сделать: какой метод создать, с какими параметрами и что он должен делать.
- Дано: значения, которые получает метод.
- Вернуть: что метод должен вернуть. Если он ничего не возвращает (void), он меняет полученный список.
- Примеры: `countTracks(["Intro", "Solo"]) -> 2` значит «вызываем метод с таким списком, и он должен вернуть 2».
- Запись `["Intro", "Solo"]` — это короткий способ показать список. В коде на Java пишите `new ArrayList<>(List.of("Intro", "Solo"))`.
- Запускайте примеры в main, чтобы проверить себя. Список можно вывести на экран напрямую: `System.out.println(tracks)`.

Тикет 1. Сколько треков в плейлисте?
Плейлист хранится как список названий треков. На странице плейлиста нужно показать, сколько в нём треков.

Что сделать: создайте метод `countTracks` с одним параметром: список строк `tracks`. Метод должен вернуть количество элементов в списке.

- Дано: tracks — список названий треков.
- Вернуть: количество треков. Для пустого списка 0.

Примеры:
- countTracks(["Intro", "Solo"]) -> 2
- countTracks([]) -> 0 (плейлист пустой)

Подсказка: Список знает, сколько в нём элементов. Посмотрите на метод `size()`.

Тикет 2. Первый трек
Когда покупатель нажимает «Играть», начинается первый трек плейлиста.

Что сделать: создайте метод `getFirstTrack` с одним параметром: список строк `tracks`. Метод должен вернуть первый элемент списка. Если список пустой, метод должен вернуть null.

- Дано: tracks — список названий треков.
- Вернуть: первое название. Для пустого списка null.

Примеры:
- getFirstTrack(["Intro", "Solo"]) -> "Intro"
- getFirstTrack([]) -> null (первого трека нет)

Подсказка: Позиции в списке считаются с 0, а `get(позиция)` читает элемент. Чтение из пустого списка бросает исключение, поэтому сначала проверьте размер.

Тикет 3. Последний трек
На странице плейлиста показано, какой трек будет играть в самом конце.

Что сделать: создайте метод `getLastTrack` с одним параметром: список строк `tracks`. Метод должен вернуть последний элемент списка. Если список пустой, метод должен вернуть null.

- Дано: tracks — список названий треков.
- Вернуть: последнее название. Для пустого списка null.

Примеры:
- getLastTrack(["Intro", "Solo"]) -> "Solo"
- getLastTrack(["Intro"]) -> "Intro" (единственный трек он же и последний)
- getLastTrack([]) -> null (последнего трека нет)

Подсказка: Позиции считаются с 0, поэтому в списке из 3 элементов последняя позиция — 2. Подумайте, как получить это число из размера.

Тикет 4. Добавить трек
Покупатель нажимает «Добавить в плейлист», и новый трек попадает в самый конец.

Что сделать: создайте метод `addTrack` с двумя параметрами: первый — список строк `tracks`, второй — строка `track`. Метод должен добавить `track` в конец списка. Он ничего не возвращает, а меняет сам `tracks`.

- Дано: tracks — список названий треков; track — название, которое нужно добавить.
- Вернуть: ничего (void). Измените сам список tracks.

Примеры:
- tracks = ["Intro"], addTrack(tracks, "Solo") -> tracks станет ["Intro", "Solo"]
- tracks = [], addTrack(tracks, "Solo") -> tracks станет ["Solo"]

Подсказка: Метод `add(элемент)` ставит элемент в конец списка.

Тикет 5. Перевернуть плейлист
Покупатель нажал «Играть с конца»: плейлист должен идти в обратном порядке.

Что сделать: создайте метод `reversePlaylist` с одним параметром: список строк `tracks`. Метод должен поменять порядок элементов на обратный в этом же списке. Он ничего не возвращает, а меняет сам `tracks`.

- Дано: tracks — список названий треков.
- Вернуть: ничего (void). Измените сам список tracks.

Примеры:
- tracks = ["a", "b", "c"], reversePlaylist(tracks) -> tracks станет ["c", "b", "a"]
- tracks = [], reversePlaylist(tracks) -> tracks останется [] (разворачивать нечего)

Подсказка: В классе `Collections` из java.util уже есть метод, который разворачивает список. Не забудьте импорт.
