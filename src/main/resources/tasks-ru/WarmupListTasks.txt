Вы работаете в службе поддержки интернет-магазина музыки. Каждый тикет ниже — это небольшая рабочая ситуация и один метод, который нужно создать. В тикете сказано, как называется метод и какие у него параметры. Заготовка показана под условием (в WarmupListTasks.java она уже есть), так что остаётся написать тело метода.
В тикетах 1–11 нужен один метод списка: size, get, add, reverse, contains, indexOf, remove, set или isEmpty.
В тикетах 12–16 нужно пройти циклом по списку длительностей треков.

Как читать тикет:
- Что сделать: какой метод создать, с какими параметрами и что он должен делать.
- Дано: значения, которые получает метод.
- Вернуть: что метод должен вернуть. Если он ничего не возвращает (void), он меняет полученный список.
- Примеры: `countTracks(["Intro", "Solo"]) -> 2` значит «вызываем метод с таким списком, и он должен вернуть 2».
- Запись `["Intro", "Solo"]` — это короткий способ показать список. В коде на Java пишите `new ArrayList<>(List.of("Intro", "Solo"))`.
- Длительности даны в секундах: `[200, 45]` — это список из двух треков, 3:20 и 0:45.
- Запускайте примеры в main, чтобы проверить себя. Список можно вывести на экран напрямую: `System.out.println(tracks)`.

Тикет 1. Сколько треков в плейлисте?
Плейлист хранится как список названий треков. На странице плейлиста нужно показать, сколько в нём треков.

Что сделать: создайте метод `countTracks` с одним параметром: список строк `tracks`. Метод должен вернуть количество элементов в списке.

- Дано: tracks — список названий треков.
- Вернуть: количество треков. Для пустого списка 0.

Примеры:
- countTracks(["Intro", "Solo"]) -> 2
- countTracks([]) -> 0 (плейлист пустой)

Подсказка: Список знает, сколько в нём элементов. Посмотрите на метод `size()`.

Тикет 2. Первый трек
Когда покупатель нажимает «Играть», начинается первый трек плейлиста.

Что сделать: создайте метод `getFirstTrack` с одним параметром: список строк `tracks`. Метод должен вернуть первый элемент списка. Если список пустой, метод должен вернуть null.

- Дано: tracks — список названий треков.
- Вернуть: первое название. Для пустого списка null.

Примеры:
- getFirstTrack(["Intro", "Solo"]) -> "Intro"
- getFirstTrack([]) -> null (первого трека нет)

Подсказка: Позиции в списке считаются с 0, а `get(позиция)` читает элемент. Чтение из пустого списка бросает исключение, поэтому сначала проверьте размер.

Тикет 6. Есть ли трек в плейлисте?
Рядом с каждым треком в магазине есть кнопка «Добавить в плейлист». Если трек уже в плейлисте, кнопка должна быть серой.

Что сделать: создайте метод `hasTrack` с двумя параметрами: первый — список строк `tracks`, второй — строка `track`. Метод должен вернуть true, если `track` есть в списке, и false, если нет.

- Дано: tracks — список названий треков; track — название, которое ищем.
- Вернуть: true, если трек есть в плейлисте, иначе false.

Примеры:
- hasTrack(["Intro", "Solo"], "Solo") -> true
- hasTrack(["Intro", "Solo"], "Outro") -> false
- hasTrack([], "Solo") -> false (в пустом плейлисте треков нет)

Подсказка: Цикл не нужен. У списка есть метод `contains(элемент)`.

Тикет 7. Где этот трек?
Покупатель спрашивает: «Каким по счёту стоит мой любимый трек?». Поддержке нужна его позиция.

Что сделать: создайте метод `findTrackPosition` с двумя параметрами: первый — список строк `tracks`, второй — строка `track`. Метод должен вернуть позицию `track` в списке. Если трека нет, метод должен вернуть -1.

- Дано: tracks — список названий треков; track — название, которое ищем.
- Вернуть: позицию трека (считая с 0). Если трека в списке нет, -1.

Примеры:
- findTrackPosition(["Intro", "Solo", "Outro"], "Solo") -> 1
- findTrackPosition(["Intro", "Solo"], "Intro") -> 0 (первая позиция — 0)
- findTrackPosition(["Intro", "Solo"], "Outro") -> -1 (такого трека нет)

Подсказка: Метод `indexOf(элемент)` возвращает позицию элемента, а если элемента нет, -1.

Тикет 8. Удалить трек по названию
Покупатель нажимает «Удалить из плейлиста» рядом с треком.

Что сделать: создайте метод `removeTrack` с двумя параметрами: первый — список строк `tracks`, второй — строка `track`. Метод должен удалить `track` из списка. Если трека нет, список остаётся как был. Метод ничего не возвращает, а меняет сам `tracks`.

- Дано: tracks — список названий треков; track — название, которое нужно удалить.
- Вернуть: ничего (void). Измените сам список tracks.

Примеры:
- tracks = ["Intro", "Solo", "Outro"], removeTrack(tracks, "Solo") -> tracks станет ["Intro", "Outro"]

Подсказка: У списка два метода `remove`. `remove(позиция)` принимает число, `remove(элемент)` принимает сам элемент. У вас есть элемент.

Тикет 9. Заменить трек
Лейбл прислал ремастер трека. Он должен встать на место старой версии, на ту же позицию.

Что сделать: создайте метод `replaceTrack` с тремя параметрами: список строк `tracks`, число `position` и строка `track`. Метод должен записать `track` на позицию `position` вместо старого названия. Размер списка не меняется. Метод ничего не возвращает, а меняет сам `tracks`. Позиция всегда существует.

- Дано: tracks — список названий треков; position — какую позицию поменять (с 0); track — новое название.
- Вернуть: ничего (void). Измените сам список tracks.

Примеры:
- tracks = ["Intro", "Solo", "Outro"], replaceTrack(tracks, 1, "Solo (Remastered)") -> tracks станет ["Intro", "Solo (Remastered)", "Outro"]
- tracks = ["Intro"], replaceTrack(tracks, 0, "Intro (Live)") -> tracks станет ["Intro (Live)"]

Подсказка: Метод `set(позиция, элемент)` записывает элемент поверх старого. Не путайте его с `add`, который делает список длиннее.

Тикет 12. Сколько длится плейлист?
На странице плейлиста показана его общая длительность. Длительности треков хранятся списком чисел в секундах.

Что сделать: создайте метод `totalDuration` с одним параметром: список чисел `durations`. Метод должен вернуть сумму всех элементов списка.

- Дано: durations — длительности треков в секундах.
- Вернуть: сумму длительностей. Для пустого списка 0.

Примеры:
- totalDuration([200, 45, 300]) -> 545
- totalDuration([]) -> 0 (пустой плейлист длится 0 секунд)

Подсказка: Пройдите по списку циклом for-each `for (int d : durations)` и прибавляйте каждый элемент к переменной, которая начинается с 0.

Тикет 16. Убрать джинглы
Совсем короткие треки (меньше 60 секунд) — это джинглы и реклама. Их нужно удалить из самого плейлиста.

Что сделать: создайте метод `removeJingles` с одним параметром: список чисел `durations`. Метод должен удалить из этого же списка все элементы меньше 60. Метод ничего не возвращает, а меняет сам `durations`.

- Дано: durations — длительности треков в секундах.
- Вернуть: ничего (void). Измените сам список durations.

Примеры:
- durations = [200, 30, 45, 300], removeJingles(durations) -> durations станет [200, 300]
- durations = [200, 300], removeJingles(durations) -> durations останется [200, 300] (удалять нечего)

Подсказка: Не удаляйте внутри `for (int d : durations)`: Java бросит ConcurrentModificationException. Идите по позициям с конца к началу и используйте `remove(позиция)` или попробуйте метод `removeIf`.
