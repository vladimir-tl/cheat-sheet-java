Вы работаете в службе поддержки интернет-магазина музыки. Каждый тикет ниже — небольшая рабочая ситуация, и каждый тикет — это один метод, который нужно дописать.

- Дано: параметры, которые получает метод.
- Вернуть: что метод должен вернуть.
- Примеры: вызовы и ожидаемые результаты. Запустите их в main, чтобы проверить себя.
---
Тикет 1. Списание или нет?
Биллинг (система оплаты) присылает вам сумму n одной платёжной операции в евро.
Если n больше 0, с клиента сняли деньги — это списание.
Если n равно 0 или меньше нуля, это не списание (пустая операция или возврат).

- Дано: n — сумма операции.
- Вернуть: true, если операция — списание, иначе false.

Примеры:
- task1(250) -> true
- task1(0) -> false
- task1(-40) -> false

Подсказка: Сравнение вида `n > 0` уже является `boolean`, его можно сразу вернуть.

Тикет 2. Какая очередь?
У каждого тикета есть номер. Тикеты с чётным номером идут в очередь A, все остальные — в очередь B.
Число чётное, если делится на 2 без остатка.

- Дано: n — номер тикета.
- Вернуть: true, если тикет идёт в очередь A (n чётное), false — если в очередь B.

Примеры:
- task2(8) -> true
- task2(7) -> false
- task2(0) -> true

Подсказка: Остаток от деления на 2, `n % 2`, отличает чётное от нечётного.

Тикет 3. Цена повыше
Два магазина-партнёра продают один и тот же альбом: первый за a евро, второй за b евро.
Менеджер хочет знать бо́льшую из двух цен.
Сравните цены сами через if-else, не используйте Math.max.

- Дано: a и b — две цены.
- Вернуть: большее число. Если цены равны, верните любую из них.

Примеры:
- task3(12, 15) -> 15
- task3(20, 9) -> 20
- task3(7, 7) -> 7

Подсказка: Сравните `a` и `b` одним `if` / `else`.

Тикет 4. Движение по счёту
Каждое движение по счёту клиента — это число n. В выписке рядом с каждым движением
пишется слово, чтобы клиент понял, что произошло.

- Дано: n — движение по счёту.
- Вернуть: "positive", если n > 0 (деньги пришли), "negative", если n < 0 (деньги ушли), "zero", если n равно 0.

Примеры:
- task4(50) -> "positive"
- task4(-20) -> "negative"
- task4(0) -> "zero"

Подсказка: Три случая: `if`, `else if`, `else`.

Тикет 5. Окно доставки
Курьер работает только в дни месяца с from по to, обе границы включены.
Клиент просит доставить заказ в день n.

- Дано: n — день, который хочет клиент; from и to — первый и последний рабочий день курьера.
- Вернуть: true, если n попадает в окно (from <= n <= to), иначе false.

Примеры:
- task5(5, 3, 10) -> true
- task5(3, 3, 10) -> true (границы включены)
- task5(11, 3, 10) -> false

Подсказка: Оба условия должны выполняться: соедините их через `&&`.

Тикет 6. Лучшее из трёх предложений
Три поставщика предложили выкупить старый запас виниловых пластинок за a, b и c евро.
Магазин принимает самое большое предложение. Не используйте Math.max.

- Дано: a, b и c — три предложения.
- Вернуть: наибольшее из трёх чисел.

Примеры:
- task6(5, 9, 2) -> 9
- task6(10, 3, 10) -> 10
- task6(-1, -5, -3) -> -1

Подсказка: Запомните самое большое значение в переменной `max` и сравните его с двумя остальными.

Тикет 7. Оценка качества поддержки
После чата клиент оценивает поддержку баллом от 0 до 100.
В ежемесячном отчёте вместо балла показывается буквенная оценка.

- Дано: score — число от 0 до 100.
- Вернуть: "A" для 90..100, "B" для 80..89, "C" для 70..79, "D" для 60..69, "F" для 0..59.

Примеры:
- task7(95) -> "A"
- task7(80) -> "B"
- task7(59) -> "F"

Подсказка: Проверяйте сверху вниз: сначала `score >= 90`, потом `score >= 80` и так далее.

Тикет 8. Фильтр контента
Магазин скрывает некоторые альбомы от молодых слушателей. Чтобы решить, что показывать,
нужно знать возрастную группу клиента.

- Дано: age — возраст клиента в годах.
- Вернуть: "child", если младше 13, "teenager" для 13..17, "adult" для 18 и старше.

Примеры:
- task8(10) -> "child"
- task8(13) -> "teenager"
- task8(18) -> "adult"

Подсказка: Сначала проверьте самую младшую группу, потом следующую; остальные взрослые.

Тикет 9. Годовая подписка
В високосном году в годовой подписке на один день больше (366 вместо 365).
Год високосный, если

- он делится на 400, или
- он делится на 4, но не делится на 100.

- Дано: year — год.
- Вернуть: true, если год високосный, иначе false.

Примеры:
- task9(2024) -> true
- task9(2023) -> false
- task9(1900) -> false (делится на 100, но не на 400)
- task9(2000) -> true (делится на 400)

Подсказка: Делится на 4 и не делится на 100, ИЛИ делится на 400. Используйте `%`, `&&` и `||`.

Тикет 10. Картонная подставка
Клиент хочет собрать треугольную подставку для дисков из трёх картонных полосок
длиной a, b и c. Треугольник получится, только если каждая полоска короче двух других
вместе: a < b + c, b < a + c и c < a + b.

- Дано: a, b и c — длины полосок.
- Вернуть: true, если треугольник собрать можно, иначе false.

Примеры:
- task10(3, 4, 5) -> true
- task10(1, 2, 3) -> false (1 + 2 не больше 3, полоски лягут в линию)
- task10(1, 1, 10) -> false

Подсказка: Каждые две стороны вместе должны быть длиннее третьей: три проверки вида `a + b > c` через `&&`.

Тикет 11. Пароль при регистрации
Новый клиент придумал пароль. Если клиент оставил поле пустым, форма присылает null
вместо текста. Пароль принимается, если он не null и в нём не меньше 8 символов.

- Дано: password — текст или null.
- Вернуть: true, если пароль принят, иначе false. На null программа не должна падать.

Примеры:
- task11("secret123") -> true
- task11("abc") -> false
- task11(null) -> false

Подсказка: Сначала проверьте `password != null`, потом длину; `&&` останавливается, если первая часть `false`.

Тикет 12. Метка одного тикета
Служба поддержки ставит на каждый тикет метку в зависимости от его номера n:

- делится на 3 и на 5: "FizzBuzz" (срочный тикет)
- делится только на 3: "Fizz" (тикет по оплате)
- делится только на 5: "Buzz" (тикет по доставке)
- всё остальное: сам номер в виде текста

- Дано: n — номер тикета.
- Вернуть: метку тикета.

Примеры:
- task12(15) -> "FizzBuzz"
- task12(9) -> "Fizz"
- task12(10) -> "Buzz"
- task12(7) -> "7"

Подсказка: Проверьте «делится и на 3, и на 5» ПЕРВЫМ (`n % 15 == 0`), иначе 15 станет Fizz. `String.valueOf(n)` превращает число в текст.
