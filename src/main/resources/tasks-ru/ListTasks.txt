Вы работаете в службе поддержки интернет-магазина музыки и следите за очередью клиентов, ожидающих помощи. Каждый тикет ниже — небольшая рабочая ситуация, и каждый тикет — это один метод, который нужно дописать. Каждому нужен один-два метода List, без циклов.

- Дано: параметры, которые получает метод.
- Вернуть: что метод должен вернуть (или как изменить список).
- Примеры: входные данные и ожидаемые результаты. Запустите их в main, чтобы проверить себя.
---
Тикет 1. Новая очередь поддержки
Смена начинается, и пока никто не ждёт. Создайте пустой список для имён клиентов.
Клиентов будут добавлять в него позже, поэтому список должен позволять добавление.

- Дано: ничего, у метода нет параметров (скобки пустые).
- Вернуть: новый пустой список.

Пример:
- task1() -> []

Подсказка: `new ArrayList<>()` даёт пустой список, в который можно добавлять.
---
Тикет 2. Утренняя смена
Уже ждут три клиента: "Anna", "Bob" и "Eve", в этом порядке.
Создайте список с их именами.

- Дано: ничего, у метода нет параметров (скобки пустые).
- Вернуть: новый список с тремя именами.

Пример:
- task2() -> ["Anna", "Bob", "Eve"]

Подсказка: Создайте пустой `ArrayList` и трижды вызовите `add`.
---
Тикет 3. Кто следующий?
Оператор освободился и вызывает следующего клиента — того, кто в начале очереди.

- Дано: list — очередь (не пустая).
- Вернуть: первое имя в списке.

Примеры:
- ["Anna", "Bob", "Eve"] -> "Anna"
- ["Tom"] -> "Tom"

Подсказка: `get(index)` читает элемент; первый индекс `0`.
---
Тикет 4. Кто пришёл последним?
Руководитель спрашивает, кто встал в очередь последним, — это последнее имя в списке.
Метод должен работать для списка любой длины.

- Дано: list — очередь (не пустая).
- Вернуть: последнее имя в списке.

Примеры:
- ["Anna", "Bob", "Eve"] -> "Eve"
- ["Tom"] -> "Tom"

Подсказка: Последний индекс равен `size() - 1`.
---
Тикет 5. Сколько ждут?
Панель показывает количество клиентов в очереди.

- Дано: list — очередь.
- Вернуть: количество имён в списке.

Примеры:
- ["Anna", "Bob", "Eve"] -> 3
- [] -> 0

Подсказка: Один метод `List` говорит, сколько в нём элементов.
---
Тикет 6. Пришёл новый клиент
Клиент с именем name встаёт в очередь — в самый конец.

- Дано: list — очередь; name — имя нового клиента.
- Вернуть: ничего. Измените полученный список.

Пример:
- list ["Anna", "Bob"], name "Eve" -> список становится ["Anna", "Bob", "Eve"]

Подсказка: `add(x)` кладёт `x` в конец списка.
---
Тикет 7. Исправление имени
Имя первого клиента набрали с ошибкой. Поставьте на его место правильное имя.
Остальные имена и размер списка не меняются.

- Дано: list — очередь (не пустая); name — правильное имя.
- Вернуть: ничего. Измените полученный список.

Пример:
- list ["Ana", "Bob"], name "Anna" -> список становится ["Anna", "Bob"]

Подсказка: `set(index, value)` заменяет элемент по индексу.
---
Тикет 8. Клиента обслужили
Первому клиенту в очереди помогли, и он уходит. Удалите первое имя —
все остальные сдвигаются на одно место вперёд.

- Дано: list — очередь (не пустая).
- Вернуть: ничего. Измените полученный список.

Пример:
- ["Anna", "Bob", "Eve"] -> список становится ["Bob", "Eve"]

Подсказка: `remove` с аргументом `int` удаляет по индексу: `remove(0)`.
---
Тикет 9. Клиент в очереди?
Клиент звонит и спрашивает: «Я уже в очереди?»

- Дано: list — очередь; name — имя клиента.
- Вернуть: true, если имя есть в списке, иначе false.

Примеры:
- list ["Anna", "Bob"], name "Bob" -> true
- list ["Anna", "Bob"], name "Eve" -> false

Подсказка: У `List` есть метод, который отвечает `true` / `false` на вопрос «есть ли внутри?».
---
Тикет 10. Место в очереди
Клиент спрашивает: «Какой я по счёту?» Место — это индекс, поэтому первое место — 0.

- Дано: list — очередь; name — имя клиента.
- Вернуть: индекс имени в списке или -1, если такого имени нет.

Примеры:
- list ["Anna", "Bob", "Eve"], name "Anna" -> 0
- list ["Anna", "Bob", "Eve"], name "Eve" -> 2
- list ["Anna", "Bob", "Eve"], name "Tom" -> -1

Подсказка: `indexOf` возвращает позицию или `-1`, если элемента нет.
---
Тикет 11. Очередь пуста?
Оператор хочет сделать перерыв, но только если никто не ждёт.

- Дано: list — очередь.
- Вернуть: true, если список пуст, иначе false.

Примеры:
- [] -> true
- ["Anna"] -> false

Подсказка: `isEmpty()` отвечает на этот вопрос напрямую.
---
Тикет 12. Счета от меньшего к большему
В списке лежат суммы сегодняшних счетов в случайном порядке. Бухгалтер хочет видеть их
отсортированными от меньшего к большему.

- Дано: numbers — суммы счетов.
- Вернуть: ничего. Отсортируйте полученный список.

Пример:
- [300, 15, 120] -> список становится [15, 120, 300]

Подсказка: Класс `Collections` умеет сортировать список на месте.
---
Тикет 13. Самый большой счёт
Менеджер хочет знать самый большой счёт за день.

- Дано: numbers — суммы счетов (не пустой список).
- Вернуть: самое большое число в списке.

Примеры:
- [40, 250, 90] -> 250
- [7] -> 7

Подсказка: В классе `Collections` есть готовый метод для самого большого элемента.
---
Тикет 14. Конец смены
Смена закончилась, и очередь передают другой команде. Удалите из списка все имена:
сам список остаётся, он просто становится пустым.

- Дано: list — очередь.
- Вернуть: ничего. Измените полученный список.

Пример:
- ["Anna", "Bob"] -> список становится []

Подсказка: Один метод удаляет все элементы разом.
