Вы работаете в службе поддержки интернет-магазина музыки. Каждый тикет ниже — небольшая рабочая ситуация, и каждый тикет — это один метод, который нужно дописать. Решайте каждый через стрим (без циклов for). Входной список менять нельзя.

- Дано: параметры, которые получает метод.
- Вернуть: что метод должен вернуть.
- Примеры: входные данные и ожидаемые результаты. Запустите их в main, чтобы проверить себя.
---
Тикет 1. Крупные счета
Бухгалтер хочет проверить только крупные счета — с суммой больше 100.
Сохраните их в том же порядке, что и во входном списке.

- Дано: totals — суммы счетов.
- Вернуть: новый список с суммами больше 100.

Примеры:
- [50, 120, 300, 100] -> [120, 300] (100 не больше 100)
- [10, 20] -> []

Подсказка: `stream()`, потом `filter` с условием, потом `toList()`.
---
Тикет 2. Цены в центах
Платёжная система работает с центами, а не с евро. Переведите каждую цену в центы
(умножьте на 100), сохранив порядок.

- Дано: prices — цены в евро.
- Вернуть: новый список с ценами в центах.

Примеры:
- [5, 12] -> [500, 1200]
- [] -> []

Подсказка: `map` меняет каждый элемент: `p -> p * 100`.
---
Тикет 3. Принтер этикеток
Принтер этикеток печатает только заглавные буквы. Переведите каждое имя клиента в верхний регистр.

- Дано: names — имена клиентов.
- Вернуть: новый список с теми же именами заглавными буквами, в том же порядке.

Пример:
- ["Anna", "bob"] -> ["ANNA", "BOB"]

Подсказка: `map` со ссылкой на метод: `String::toUpperCase`.
---
Тикет 4. Срочные тикеты
В списке лежит приоритет каждого открытого тикета: 1 — «срочно», большие числа — менее срочно.
Сколько срочных тикетов?

- Дано: priorities — приоритет каждого тикета.
- Вернуть: сколько элементов равны 1 (как long, потому что count() возвращает long).

Примеры:
- [1, 3, 1, 2] -> 2
- [2, 3] -> 0

Подсказка: `filter` для срочных, потом `count()`.
---
Тикет 5. Выручка за день
В списке лежат суммы сегодняшних счетов. Сложите их.

- Дано: totals — суммы счетов.
- Вернуть: сумму всех счетов или 0 для пустого списка.

Примеры:
- [10, 25, 5] -> 40
- [] -> 0

Подсказка: `mapToInt(Integer::intValue)` даёт `IntStream`, а у него есть `sum()`.
---
Тикет 6. Средняя оценка
Клиенты оценили поддержку от 1 до 5. Найдите среднюю оценку с дробной частью.

- Дано: ratings — оценки.
- Вернуть: среднее оценок или 0, если список пуст (пока никто не оценил).

Примеры:
- [5, 4] -> 4.5
- [5, 4, 3] -> 4.0
- [] -> 0.0

Подсказка: У `IntStream` есть `average()`; он возвращает `OptionalDouble`, поэтому для пустого списка используйте `orElse(0)`.
---
Тикет 7. Самый большой счёт
Менеджер хочет видеть самый большой счёт за день.

- Дано: totals — суммы счетов.
- Вернуть: самую большую сумму или -1, если список пуст (сегодня счетов нет).

Примеры:
- [40, 250, 90] -> 250
- [] -> -1

Подсказка: `max(Integer::compare)` возвращает `Optional`; `orElse(-1)` обработает пустой список.
---
Тикет 8. Топ-3 счетов
Менеджер хочет три самых больших счёта, самый большой — первым.
Если счетов меньше трёх, верните все, самый большой — первым.

- Дано: totals — суммы счетов.
- Вернуть: новый список не более чем из 3 самых больших сумм, от большей к меньшей.

Примеры:
- [5, 12, 8, 20, 3] -> [20, 12, 8]
- [7, 9] -> [9, 7]

Подсказка: `sorted(Comparator.reverseOrder())`, потом `limit(3)`.
---
Тикет 9. Страны наших клиентов
В списке лежит страна каждого заказа, поэтому страны повторяются. Маркетингу нужна
каждая страна по одному разу, в порядке первого появления.

- Дано: countries — страна каждого заказа.
- Вернуть: новый список без повторов.

Пример:
- ["USA", "Brazil", "USA", "Estonia"] -> ["USA", "Brazil", "Estonia"]

Подсказка: Одна операция потока убирает повторы и сохраняет порядок.
---
Тикет 10. Есть возврат?
В списке лежат движения по счёту: платёж — положительное число, возврат — отрицательное.
Есть ли хотя бы один возврат?

- Дано: movements — движения по счёту.
- Вернуть: true, если хотя бы одно число меньше 0, иначе false.

Примеры:
- [50, -20, 30] -> true
- [50, 30] -> false
- [0] -> false

Подсказка: `anyMatch` отвечает на вопрос «есть ли хотя бы один?».
---
Тикет 11. Все заказы оплачены?
В списке лежит оплаченная сумма каждого заказа. Заказ оплачен, если сумма больше 0.
Все ли заказы оплачены?

- Дано: amounts — оплаченные суммы.
- Вернуть: true, если каждая сумма больше 0, иначе false. Для пустого списка верните true (неоплаченных заказов нет).

Примеры:
- [10, 20] -> true
- [10, 0, 20] -> false
- [] -> true

Подсказка: `allMatch` отвечает на вопрос «все ли ...?».
---
Тикет 12. Первое длинное название
Ведущему радио нужно длинное название трека. Найдите первое название длиннее 10 символов.

- Дано: titles — названия треков.
- Вернуть: первое название, в котором больше 10 символов, или "none", если такого нет.

Примеры:
- ["Intro", "Bohemian Rhapsody", "Yesterday Once More"] -> "Bohemian Rhapsody"
- ["Intro", "Help"] -> "none"

Подсказка: `filter` по `length()`, потом `findFirst()`, потом `orElse("none")`.
---
Тикет 13. Список рассылки
Почтовому сервису нужны все имена клиентов одной строкой через запятую и пробел.
После последнего имени запятой нет.

- Дано: names — имена клиентов.
- Вернуть: один текст со всеми именами.

Примеры:
- ["Anna", "Bob", "Eve"] -> "Anna, Bob, Eve"
- ["Anna"] -> "Anna"
- [] -> ""

Подсказка: `collect(Collectors.joining(", "))` склеивает строки через разделитель.
---
Тикет 14. Клиенты по странам
В списке лежит страна каждого заказа. Сколько заказов пришло из каждой страны?

- Дано: countries — страна каждого заказа.
- Вернуть: словарь: страна -> число заказов из неё. Числа типа Long, потому что counting() считает в long.

Примеры:
- ["USA", "Brazil", "USA"] -> {USA=2, Brazil=1}
- [] -> {}

Подсказка: `Collectors.groupingBy(c -> c, Collectors.counting())` считает каждое значение.
