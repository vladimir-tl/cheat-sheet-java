Вы работаете в службе поддержки интернет-магазина музыки. Каждый тикет ниже — небольшая рабочая ситуация, и каждый тикет — это один метод, который нужно дописать. Словари записаны здесь как {ключ=значение, ...} — так их печатает Java. У HashMap нет постоянного порядка, поэтому пары могут печататься в другом порядке.

- Дано: параметры, которые получает метод.
- Вернуть: что метод должен вернуть (или что напечатать).
- Примеры: входные данные и ожидаемые результаты. Запустите их в main, чтобы проверить себя.
---
Тикет 1. Карточки клиентов
CRM хранит карточку каждого клиента: имя — ключ, возраст — значение.
Создайте Map<String, Integer> с тремя клиентами, например Anna 25, Bob 30 и Eve 22.

- Дано: ничего, у метода нет параметров (скобки пустые).
- Вернуть: новый словарь с тремя парами имя -> возраст.

Пример:
- task1() -> {Anna=25, Bob=30, Eve=22}

Подсказка: Создайте `HashMap` и вызовите `put(key, value)` для каждого клиента.
---
Тикет 2. Поиск в CRM
Клиент звонит и называет своё имя. Найдите его возраст в CRM.
Если карточки с таким именем нет, верните -1.

- Дано: map — карточки (имя -> возраст); key — имя.
- Вернуть: возраст для этого имени или -1, если такого ключа в словаре нет.

Примеры:
- map {Anna=25, Bob=30}, key "Bob" -> 30
- map {Anna=25, Bob=30}, key "Tom" -> -1

Подсказка: `getOrDefault(key, defaultValue)` возвращает значение по умолчанию, если ключа нет.
---
Тикет 3. Клиент зарегистрирован?
Прежде чем завести новую карточку, оператор проверяет, что у клиента её ещё нет.

- Дано: map — карточки (имя -> возраст); key — имя.
- Вернуть: true, если такой ключ есть в словаре, иначе false.

Примеры:
- map {Anna=25}, key "Anna" -> true
- map {Anna=25}, key "Tom" -> false

Подсказка: `Map` умеет проверить, есть ли ключ, не читая значение.
---
Тикет 4. Список для менеджера
Менеджер хочет видеть все карточки клиентов. Пройдите по словарю и напечатайте каждую пару
в виде имя=возраст, каждую на отдельной строке.

- Дано: map — карточки (имя -> возраст).
- Вернуть: ничего, метод печатает в консоль.

Ожидаемый вывод для {Anna=25, Bob=30} (порядок строк может отличаться):

  Anna=25
  Bob=30

Подсказка: Пройдите циклом по `map.entrySet()`; у каждой записи есть `getKey()` и `getValue()`.
---
Тикет 5. Сумма заказа
В словаре лежат товары одного заказа: название товара — ключ, его цена — значение.
Клиент хочет знать итоговую сумму.

- Дано: map — товары (название -> цена).
- Вернуть: сумму всех цен (всех значений) или 0 для пустого словаря.

Примеры:
- {Vinyl=30, CD=15, Poster=5} -> 50
- {} -> 0

Подсказка: `map.values()` даёт все цены; сложите их в цикле.
---
Тикет 6. Статистика опечаток
Отдел качества изучает сообщения клиентов. Посчитайте, сколько раз каждый символ
встречается в тексте. Пробелы и знаки препинания — тоже символы.

- Дано: s — текст.
- Вернуть: новый словарь: символ -> сколько раз он встречается.

Примеры:
- task6("aab") -> {a=2, b=1}
- task6("hello") -> {h=1, e=1, l=2, o=1}
- task6("") -> {}

Подсказка: Пройдите циклом по `s.toCharArray()`. Для каждого символа `c` запишите `getOrDefault(c, 0) + 1`.
