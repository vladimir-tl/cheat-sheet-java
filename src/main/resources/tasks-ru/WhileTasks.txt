Вы работаете в службе поддержки интернет-магазина музыки. Каждый тикет ниже — небольшая рабочая ситуация, и каждый тикет — это один метод, который нужно дописать с помощью цикла while.

- Дано: параметры, которые получает метод.
- Вернуть: что метод должен вернуть (или что напечатать).
- Примеры: вызовы и ожидаемые результаты. Запустите их в main, чтобы проверить себя.
---
Тикет 1. Открытые тикеты
На панели показаны номера первых 10 открытых тикетов.
Напечатайте числа от 1 до 10, каждое на отдельной строке.

- Дано: ничего, у метода нет параметров (скобки пустые).
- Вернуть: ничего, метод печатает в консоль.

Ожидаемый вывод (10 строк):

  1
  2
  3
  ...
  10

Подсказка: Создайте `i = 1` до цикла и не забудьте `i++` внутри, иначе цикл не закончится.

Тикет 3. Баллы лояльности
Клиент получает 1 балл за первый заказ, 2 балла за второй, 3 за третий и так далее.
Сколько баллов у клиента после n заказов? Иначе говоря, посчитайте 1 + 2 + ... + n.

- Дано: n — количество заказов (n >= 0).
- Вернуть: общее число баллов.

Примеры:
- task3(5) -> 15 (1 + 2 + 3 + 4 + 5)
- task3(1) -> 1
- task3(0) -> 0

Подсказка: Две переменные до цикла: `sum` и счётчик `i`.

Тикет 4. Длина номера заказа
Принтеру этикеток нужно знать, сколько цифр в номере заказа, чтобы выбрать размер шрифта.
Подсказка: `n / 10` отбрасывает последнюю цифру (`12345 / 10` = `1234`). Посчитайте, сколько раз это можно сделать, пока `n > 0`. Осторожно с `n = 0`: в нём 1 цифра.

- Дано: n — номер заказа (n >= 0).
- Вернуть: количество цифр в n. У числа 0 одна цифра.

Примеры:
- task4(12345) -> 5
- task4(7) -> 1
- task4(0) -> 1

Тикет 5. Контрольная сумма номера заказа
Чтобы ловить опечатки, система проверяет контрольную сумму номера заказа — сумму всех его цифр.
Подсказка: `n % 10` это последняя цифра (`123 % 10` = `3`), `n / 10` её отбрасывает (`123 / 10` = `12`).

- Дано: n — номер заказа (n >= 0).
- Вернуть: сумму цифр n.

Примеры:
- task5(123) -> 6 (1 + 2 + 3)
- task5(9045) -> 18
- task5(0) -> 0

Тикет 6. Перевёрнутый номер заказа
Старая складская система хранит номера заказов задом наперёд. Переверните число:
последняя цифра становится первой. Работайте с цифрами (`% 10` и `/ 10`), а не с текстом.

- Дано: n — номер заказа (n >= 0).
- Вернуть: число с цифрами в обратном порядке.

Примеры:
- task6(123) -> 321
- task6(5) -> 5
- task6(1200) -> 21 (нули в начале пропадают)

Подсказка: Берите последнюю цифру через `n % 10` и дописывайте: `reversed = reversed * 10 + digit`.

Тикет 7. Уменьшение картинки
Фото товара шириной n пикселей. Сайт снова и снова делит ширину пополам (целочисленно, n / 2),
пока она больше 1 пикселя. Сколько делений понадобится?

- Дано: n — ширина в пикселях (n >= 1).
- Вернуть: количество делений.

Примеры:
- task7(16) -> 4 (16, 8, 4, 2, 1)
- task7(10) -> 3 (10, 5, 2, 1)
- task7(1) -> 0

Подсказка: Пока `n > 1`: делайте `n /= 2` и считайте шаги.

Тикет 8. Равные пачки треков
У клиента два плейлиста: в одном a треков, в другом b. Он хочет разбить оба на пачки
одинакового размера без остатка, и пачки должны быть как можно больше. Этот размер —
наибольший общий делитель a и b.
Найдите его алгоритмом Евклида: пока b не 0, заменяйте пару (a, b) на (b, a % b).
Когда b станет 0, ответ — a.

- Дано: a и b — размеры плейлистов (`a > 0`, `b > 0`).
- Вернуть: наибольший общий делитель a и b.

Примеры:
- task8(12, 18) -> 6
- task8(20, 10) -> 10
- task8(7, 5) -> 1

Подсказка: Алгоритм Евклида: пока `b != 0`, заменяйте `(a, b)` на `(b, a % b)`. Ответ в `a`.

Тикет 9. Первый возврат
В массиве лежат движения по счёту клиента в порядке времени; возврат — отрицательное число.
Найдите, где первый возврат: идите по массиву и остановитесь на первом отрицательном числе.

- Дано: arr — движения по счёту.
- Вернуть: индекс первого отрицательного числа или -1, если его нет.

Примеры:
- [50, 20, -10, -5] -> 2
- [-1, 5] -> 0
- [10, 20] -> -1

Подсказка: Идите по индексу, пока `i < arr.length`; верните `i`, как только `arr[i] < 0`.

Тикет 10. Игра бота поддержки
Бот поддержки играет со скучающим клиентом. Он начинает с числа n и повторяет шаг,
пока n не станет 1:

- если n чётное, разделить его на 2
- если n нечётное, n становится 3 * n + 1

- Дано: n — начальное число (n >= 1).
- Вернуть: сколько шагов понадобилось, чтобы дойти до 1.

Примеры:
- task10(6) -> 8 (6, 3, 10, 5, 16, 8, 4, 2, 1)
- task10(4) -> 2 (4, 2, 1)
- task10(1) -> 0

Подсказка: Повторяйте, пока `n != 1`, меняйте `n` по правилу и считайте шаги.
