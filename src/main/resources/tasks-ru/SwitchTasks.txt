Вы работаете в службе поддержки интернет-магазина музыки. Каждый тикет ниже — небольшая рабочая ситуация, и каждый тикет — это один метод, который нужно дописать с помощью switch.

- Дано: параметры, которые получает метод.
- Вернуть: что метод должен вернуть.
- Примеры: вызовы и ожидаемые результаты. Запустите их в main, чтобы проверить себя.
---
Тикет 1. День доставки
Система доставки хранит день недели числом: 1 — понедельник, 2 — вторник ... 7 — воскресенье.
В письме клиенту нужно показать название дня.

- Дано: day — число.
- Вернуть: "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday" или "Sunday" для 1..7 и "Unknown" для любого другого числа.

Примеры:
- task1(1) -> "Monday"
- task1(7) -> "Sunday"
- task1(9) -> "Unknown"

Подсказка: По одному `case` на каждый день и `default` для всего остального.
---
Тикет 2. Сокращённые часы поддержки
В выходные поддержка работает по сокращённому графику. Дни пронумерованы как в тикете 1:
1 — понедельник ... 6 — суббота, 7 — воскресенье.

- Дано: day — число.
- Вернуть: true для 6 и 7 (выходной), false для любого другого числа.

Примеры:
- task2(6) -> true
- task2(7) -> true
- task2(3) -> false
- task2(0) -> false

Подсказка: Один `case` может перечислять несколько значений: `case 6, 7 ->`.
---
Тикет 3. Расчётный период
Месячная подписка оплачивается за каждый день месяца, поэтому биллингу нужно число дней
в месяце. В феврале здесь всегда 28 дней.

- Дано: month — число (1 — январь ... 12 — декабрь).
- Вернуть: 31 для месяцев 1, 3, 5, 7, 8, 10, 12; 30 для 4, 6, 9, 11; 28 для 2; -1 для любого другого числа.

Примеры:
- task3(1) -> 31
- task3(4) -> 30
- task3(2) -> 28
- task3(13) -> -1

Подсказка: Объедините месяцы с одинаковым числом дней в один `case`.
---
Тикет 4. Сезонный плейлист
На главной странице показывается плейлист текущего сезона. Определите сезон по месяцу.

- Дано: month — число (1 — январь ... 12 — декабрь).
- Вернуть: "Winter" для 12, 1, 2; "Spring" для 3, 4, 5; "Summer" для 6, 7, 8; "Autumn" для 9, 10, 11; "Not a month" для любого другого числа.

Примеры:
- task4(1) -> "Winter"
- task4(7) -> "Summer"
- task4(10) -> "Autumn"
- task4(14) -> "Not a month"

Подсказка: По три месяца на сезон, перечисленные в одном `case`.
---
Тикет 5. Голосовой бот
Голосовой бот слышит слово и должен превратить его в число для телефонного меню.
Он знает только три слова, написанных маленькими буквами.

- Дано: word — распознанное слово.
- Вернуть: 1 для "one", 2 для "two", 3 для "three", 0 для любого другого слова.

Примеры:
- task5("one") -> 1
- task5("three") -> 3
- task5("five") -> 0

Подсказка: `switch` работает и со `String`: `case "one" ->`.
---
Тикет 6. Калькулятор возврата в боте
Клиент просит чат-бота посчитать: два числа и оператор между ними.
Бот знает четыре оператора: "+", "-", "*" и "/". Деление целочисленное: 7 / 2 даёт 3.

- Дано: a — первое число; operator — оператор в виде текста; b — второе число.
- Вернуть: результат "a operator b" или 0, если оператор неизвестен.

Примеры:
- task6(5, "+", 3) -> 8
- task6(5, "-", 3) -> 2
- task6(4, "*", 3) -> 12
- task6(7, "/", 2) -> 3
- task6(5, "%", 3) -> 0

Подсказка: Сделайте `switch` по `operator` и в каждом `case` посчитайте `a + b`, `a - b` и так далее.
---
Тикет 7. Подсказка при диктовке
Бот помогает клиентам, которые диктуют имя по буквам. Для каждой буквы он должен знать,
гласная ли она. Гласные — a, e, i, o, u. Буква всегда приходит маленькой.

- Дано: c — одна буква (char).
- Вернуть: true, если c — гласная, иначе false.

Примеры:
- task7('a') -> true
- task7('u') -> true
- task7('b') -> false

Подсказка: `case` для `char` пишется в одинарных кавычках: `case 'a', 'e' ->`.
---
Тикет 8. Оценка клиента
После доставки клиент оценивает заказ числом от 1 до 5. В отчёте вместо числа показывается слово.

- Дано: grade — оценка.
- Вернуть: "Excellent" для 5, "Good" для 4, "Satisfactory" для 3, "Fail" для 2 или 1, "Invalid" для любого другого числа.

Примеры:
- task8(5) -> "Excellent"
- task8(3) -> "Satisfactory"
- task8(1) -> "Fail"
- task8(0) -> "Invalid"

Подсказка: Оценки 1 и 2 могут быть в одном `case`: `case 2, 1 ->`.
---
Тикет 9. Робот на складе
Складской робот упёрся в стену и должен развернуться — поехать в противоположную сторону.
UP и DOWN противоположны, LEFT и RIGHT тоже.
Используйте switch-выражение (return switch (...) { case ... -> ...; }).

- Дано: direction — одно из UP, DOWN, LEFT, RIGHT.
- Вернуть: противоположное направление.

Примеры:
- task9(Direction.UP) -> Direction.DOWN
- task9(Direction.LEFT) -> Direction.RIGHT

Подсказка: В `switch` по enum константы пишутся без имени типа: `case UP ->`.
---
Тикет 10. Программа лояльности
Участники программы лояльности получают скидку, которая зависит от типа карты.

- Дано: type — тип карты в виде текста.
- Вернуть: скидку в процентах: 20 для "gold", 10 для "silver", 5 для "bronze", 0 для любого другого типа.

Примеры:
- task10("gold") -> 20
- task10("bronze") -> 5
- task10("platinum") -> 0

Подсказка: По одному `case` на тип карты и `default -> 0`.
