Вы работаете в службе поддержки интернет-магазина музыки. Каждый тикет ниже — это небольшая рабочая ситуация и один метод, который нужно создать. В тикете сказано, как называется метод и какие у него параметры. Заготовка показана под условием (в WarmupTasks.java она уже есть), так что остаётся написать тело метода.
В задачах только массивы, циклы, примитивы и null. Они идут от простых к чуть более сложным.

Как читать тикет:
- Что сделать: какой метод создать, с какими параметрами и что он должен делать.
- Дано: значения, которые получает метод.
- Вернуть: что метод должен вернуть. Если он ничего не возвращает (void), он меняет полученный массив.
- Примеры: `findBestSeller([3, 17, 9]) -> 17` значит «вызываем метод с таким массивом, и он должен вернуть 17».
- Запись `[3, 17, 9]` — это короткий способ показать массив. В коде на Java пишите `new int[]{3, 17, 9}`.
- Запускайте примеры в main, чтобы проверить себя. Чтобы вывести массив на экран, используйте `Arrays.toString(arr)`.

Тикет 1. Есть ли трек в плейлисте?
Плейлист хранится как массив чисел: каждое число — это id одного трека.
Покупатель спрашивает: «Есть ли этот трек в моём плейлисте?»

Что сделать: создайте метод `containsTrack` с двумя параметрами: первый — массив чисел `ids`, второй — число `target`. Метод должен проверить, есть ли `target` в массиве `ids`, и вернуть true или false.

- Дано: ids — массив id треков; target — id трека, который ищем.
- Вернуть: true, если target есть в массиве, иначе false. Для пустого массива тоже false.

Примеры:
- containsTrack([5, 8, 12], 8) -> true (8 есть в массиве)
- containsTrack([5, 8, 12], 7) -> false (числа 7 нет)
- containsTrack([], 7) -> false (плейлист пустой)

Подсказка: Смотрите на элементы по одному. Как только нашли target, ответ уже известен и его можно вернуть.

Каждое число в массиве показывает, сколько копий одного альбома продано сегодня.

- Дано: sales — массив проданных копий (каждое число 0 или больше).

Примеры:

- findBestSeller([4]) -> 4 (единственное число и есть самое большое)

Подсказка: Запоминайте самое большое число из тех, что уже видели, и сравнивайте с ним каждый следующий элемент.

Тикет 3. Поменять два трека местами
Покупатель перетаскивает один трек на место другого, и эти два трека меняются местами.
Все остальные треки остаются там же, где были.

Что сделать: создайте метод `swapTracks` с тремя параметрами: первый — массив чисел `arr`, второй — число `i`, третий — число `j`. Числа `i` и `j` — это позиции (индексы) в массиве, они считаются с 0. Метод должен поменять местами элементы на этих двух позициях. Он ничего не возвращает, а меняет сам `arr`.

- Дано: arr — плейлист; i и j — два индекса. Оба всегда есть в массиве.
- Вернуть: ничего (void). Измените сам массив arr.

Примеры:
- arr = [1, 2, 3, 4], swapTracks(arr, 0, 3) -> arr станет [4, 2, 3, 1] (первый и последний поменялись местами)
- arr = [1, 2, 3], swapTracks(arr, 1, 1) -> arr останется [1, 2, 3] (i и j — одна и та же позиция)

Подсказка: Если сразу записать значение arr[j] в arr[i], старое значение arr[i] потеряется. Сначала сохраните его в дополнительной переменной.

Тикет 4. Играть задом наперёд
Покупатель нажал «Играть с конца»: плейлист должен идти в обратном порядке.

Что сделать: создайте метод `reversePlaylist` с одним параметром: массив чисел `arr`. Метод должен развернуть массив: последний элемент становится первым, предпоследний — вторым и так далее. Меняйте этот же массив, второй не создавайте. Метод ничего не возвращает.

Примеры:

Подсказка: Поменяйте первый элемент с последним, второй с предпоследним и остановитесь, когда дойдёте до середины.

Тикет 5. Цены идут по порядку?
На странице магазина цены должны идти от самой низкой к самой высокой.
Перед публикацией список нужно проверить.

Что сделать: создайте метод `arePricesInOrder` с одним параметром: массив чисел `prices`. Метод должен проверить, что каждая цена не меньше цены прямо перед ней, и вернуть true или false. Две одинаковые цены подряд — это нормально.

- Дано: prices — массив цен.
- Вернуть: true, если цены идут по порядку, иначе false. Для пустого массива или одной цены верните true.

Примеры:
- arePricesInOrder([1, 3, 3, 8]) -> true (каждая цена не меньше предыдущей)
- arePricesInOrder([1, 5, 4]) -> false (4 идёт после 5)
- arePricesInOrder([]) -> true (цен нет, значит, и беспорядка нет)

Подсказка: Сравнивайте соседей: элемент и тот, что стоит прямо перед ним. Начните со второго элемента, потому что перед первым ничего нет. Для ответа достаточно одной неправильной пары.

- Вернуть: ничего (void). Измените сам массив arr.

Подсказка: Заведите дополнительный индекс: место, куда должно попасть следующее ненулевое число. Когда все ненулевые числа окажутся на местах, подумайте, что должно быть в оставшихся ячейках.

Тикет 7. Нарастающий итог
Каждое число — это выручка за один день.
В отчёте нужно показать, сколько магазин заработал всего к концу каждого дня.

Что сделать: создайте метод `runningTotal` с одним параметром: массив чисел `arr`. Метод должен создать и вернуть новый массив, в котором каждый элемент — это сумма всех чисел `arr` от начала до этой позиции включительно.

- Дано: arr — выручка по дням.
- Вернуть: новый массив той же длины. Сам arr не меняйте. Для пустого массива верните пустой массив.

Примеры:
- runningTotal([1, 2, 3, 4]) -> [1, 3, 6, 10] (1, затем 1+2, затем 1+2+3, затем 1+2+3+4)
- runningTotal([5, -2, 4]) -> [5, 3, 7] (5, затем 5-2, затем 5-2+4)
- runningTotal([]) -> []

Подсказка: Не нужно считать сумму заново для каждой позиции. Храните сумму на данный момент и на каждом шаге прибавляйте одно число.

Тикет 8. Два альбома на подарочную карту
У покупателя есть подарочная карта, и он хочет потратить её полностью ровно на два разных альбома.

Что сделать: создайте метод `findAlbumsForGiftCard` с двумя параметрами: первый — массив чисел `prices`, второй — число `amount`. Метод должен найти две разные позиции в массиве, цены на которых в сумме дают ровно `amount`, и вернуть эти позиции (индексы, а не цены) в виде массива.

- Дано: prices — цены альбомов; amount — сумма на подарочной карте.
- Вернуть: массив из двух индексов, сначала меньший. Если такой пары нет, верните пустой массив. Если пар несколько, верните любую.

Примеры:
- findAlbumsForGiftCard([2, 7, 11, 15], 9) -> [0, 1] (на индексах 0 и 1 стоят цены 2 и 7, а 2 + 7 = 9)

Подсказка: Переберите все пары альбомов. Для этого нужен цикл внутри цикла. Индекс второго альбома всегда должен быть больше индекса первого.

Тикет 9. Потерянный номер билета
У билетов на концерт номера от 0 до n без пропусков, на каждый номер один билет.
Один билет потерялся. В массиве лежат номера всех остальных билетов, в любом порядке. Билет с самым большим номером n точно не потерялся.

Что сделать: создайте метод `findLostTicket` с одним параметром: массив чисел `arr`. Метод должен найти номер потерянного билета и вернуть его.

- Дано: arr — номера оставшихся билетов, без повторов. n — самое большое число в массиве.
- Вернуть: число от 0 до n, которого нет в массиве.

Примеры:
- findLostTicket([3, 0, 1]) -> 2 (самый большой номер 3, значит, были билеты 0, 1, 2, 3. Не хватает 2)

- findLostTicket([1]) -> 0 (самый большой номер 1, значит, были билеты 0, 1. Не хватает 0)

Подсказка: Сначала найдите самое большое число в массиве, это n. Потом посчитайте, чему должна равняться сумма всех чисел от 0 до n, и сравните её с реальной суммой массива.

Тикет 10. Код специального предложения
Промокод работает, только если он простое число. Простое число больше 1 и делится без остатка только на 1 и на само себя: 2, 3, 5, 7, 11, ...

Что сделать: создайте метод `isPrime` с одним параметром: число `n`. Метод должен проверить, простое ли число `n`, и вернуть true или false.

- Дано: n — промокод.
- Вернуть: true, если n простое, иначе false.

Примеры:
- isPrime(7) -> true (7 делится только на 1 и на 7)
- isPrime(12) -> false (12 делится ещё на 2, 3, 4 и 6)
- isPrime(1) -> false (простое число должно быть больше 1)
- isPrime(2) -> true (самое маленькое простое число)

Подсказка: Попробуйте делить n на 2, 3, 4 и так далее. Если какое-то из них делит n без остатка, n не простое. Числа меньше 2 никогда не бывают простыми, поэтому обработайте их первыми.

Тикет 11. Зеркальное название альбома
Некоторые названия читаются одинаково слева направо и справа налево, например "level".
Такое слово называется палиндромом, и магазин хочет отмечать такие альбомы.

Что сделать: создайте метод `isPalindrome` с одним параметром: строка `s`. Метод должен проверить, является ли `s` палиндромом, и вернуть true или false. Заглавные и строчные буквы считаются разными, поэтому "Level" — не палиндром.

- Дано: s — название. Может быть null: это значит, что названия нет совсем.
- Вернуть: true, если s — палиндром, иначе false. Пустая строка и строка из одной буквы — палиндромы. Для null верните false.

Примеры:
- isPalindrome("level") -> true
- isPalindrome("abca") -> false (вторая буква b, предпоследняя c)
- isPalindrome("Level") -> false (L и l — разные буквы)
- isPalindrome("") -> true
- isPalindrome(null) -> false

Подсказка: Сначала разберитесь с null. Затем сравните первую букву с последней, вторую с предпоследней и так далее до середины. `s.charAt(i)` даёт букву на позиции i.

Тикет 12. Наборы пластинок
Наборы пластинок выпускают только по 1, 2, 4, 8, 16, ... штук: каждый размер вдвое больше предыдущего.
Такие числа называются степенями двойки. Покупатель просит набор из n пластинок.

Что сделать: создайте метод `isPowerOfTwo` с одним параметром: число `n`. Метод должен проверить, является ли `n` одним из этих размеров, и вернуть true или false.

- Дано: n — запрошенный размер. Может быть также 0 или отрицательным.
- Вернуть: true, если n — степень двойки (1, 2, 4, 8, ...), иначе false.

Примеры:
- isPowerOfTwo(16) -> true
- isPowerOfTwo(12) -> false (после 8 сразу идёт 16)
- isPowerOfTwo(1) -> true (самый маленький размер)

Подсказка: Делите n на 2, пока оно чётное. Что в итоге останется от степени двойки? Ноль и отрицательные числа обработайте первыми.

Тикет 13. Сумма бонусных баллов
Бонусные баллы приходят из другой системы. У массива тип Integer[], а не int[], потому что Integer может быть null: это значит, что система не знает баллы этого клиента.
Иногда null весь массив: система ничего не прислала.

Что сделать: создайте метод `sumBonusPoints` с одним параметром: массив `bonuses` типа `Integer[]`. Метод должен сложить все известные баллы, пропустить каждый null и вернуть сумму.

- Дано: bonuses — массив баллов; он сам может быть null и может содержать элементы null.
- Вернуть: сумму всех чисел в массиве. Если массив равен null, верните 0.

Примеры:
- sumBonusPoints([10, null, 5]) -> 15 (10 + 5, null пропущен)
- sumBonusPoints([null, null]) -> 0 (известных баллов нет)
- sumBonusPoints(null) -> 0 (массива нет совсем)

Подсказка: Здесь null может быть в двух местах: сам массив и каждый элемент. Использование Integer, равного null, в вычислениях бросает NullPointerException.

Тикет 14. Есть ли комментарий?
Покупатели могут оставить комментарий к заказу. Если поле оставили пустым, сайт может прислать null, пустую строку или строку из пробелов. Всё это не настоящий комментарий.

Тикет 15. Цифра из символа
Серийный номер читают по одному символу. Символ '7' и число 7 — это разные вещи: внутри Java символ '7' хранится как код 55.

Тикет 16. Сумма заказа без переполнения
Сумма заказа равна price * quantity. В int помещаются числа примерно до 2,1 миллиарда.
Если результат больше, Java не сообщает об ошибке: вы просто получаете неверное число. Это называется переполнением.

Что сделать: создайте метод `totalPrice` с двумя параметрами: первый — число `price`, второй — число `quantity`, оба типа `int`. Метод должен перемножить их и вернуть точный результат в виде `long`, даже если он не помещается в `int`.

- Дано: price и quantity — два числа типа int.
- Вернуть: точный результат умножения в виде long.

Примеры:
- totalPrice(3, 4) -> 12
- totalPrice(2000000000, 3) -> 6000000000 (слишком много для int)

Подсказка: `price * quantity` считается в int и может переполниться раньше, чем попадёт в long. Сделайте так, чтобы вычисление шло в long.
