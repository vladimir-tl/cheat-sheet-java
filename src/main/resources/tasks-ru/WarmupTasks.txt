Вы работаете в службе поддержки интернет-магазина музыки. Каждый тикет ниже — небольшая рабочая ситуация, и каждый тикет — это один метод, который нужно дописать.
В задачах только массивы, циклы, примитивы и null, без коллекций. Они идут от простых к чуть более сложным. Всегда думайте о крайних случаях: пустой массив, null, ноль.

- Дано: параметры, которые получает метод.
- Вернуть: что метод должен вернуть (или как изменить массив).
- Примеры: входные данные и ожидаемые результаты. Запустите их в main, чтобы проверить себя.
---
Тикет 1. Есть ли трек в плейлисте?
Плейлист — это массив id треков. Покупатель спрашивает, есть ли в нём один трек.

- Дано: ids — id треков в плейлисте; target — id, который ищем.
- Вернуть: true, если target есть в ids, иначе false (для пустого массива тоже false).

Примеры:
- task1([5, 8, 12], 8) -> true
- task1([5, 8, 12], 7) -> false
- task1([], 7) -> false

Подсказка: Пройдите по массиву циклом for и сразу делайте `return true`, как только встретили target; после цикла `return false`.

Тикет 2. Бестселлер
В массиве лежит, сколько копий каждого альбома продано сегодня. Найдите самое большое число.

- Дано: sales — числа проданных копий (все 0 или больше).
- Вернуть: самый большой элемент или -1, если массив пустой.

Примеры:
- task2([3, 17, 9]) -> 17
- task2([4]) -> 4
- task2([]) -> -1

Подсказка: Возьмите первый элемент как текущий максимум и сравнивайте с ним все остальные. Не начинайте с 0, если данные могут быть отрицательными.
---
Тикет 3. Поменять два трека местами
Два трека в плейлисте нужно поменять местами.

- Дано: arr — плейлист; i и j — два допустимых индекса в нём.
- Вернуть: ничего. Измените сам массив.

Примеры:
- arr = [1, 2, 3, 4], task3(arr, 0, 3) -> arr станет [4, 2, 3, 1]
- arr = [1, 2, 3], task3(arr, 1, 1) -> arr останется [1, 2, 3]

Подсказка: Нужна третья переменная: сохраните `arr[i]` в `temp`, затем `arr[i] = arr[j]`, затем `arr[j] = temp`.
---
Тикет 4. Играть задом наперёд
Переверните плейлист: последний трек становится первым и так далее.
Сделайте это в том же массиве, новый не создавайте.

- Дано: arr — плейлист.
- Вернуть: ничего. Измените сам массив.

Примеры:
- arr = [1, 2, 3, 4, 5], task4(arr) -> arr станет [5, 4, 3, 2, 1]
- arr = [7, 8], task4(arr) -> arr станет [8, 7]
- arr = [], task4(arr) -> arr останется []

Подсказка: Два индекса: `left = 0` и `right = arr.length - 1`. Меняйте элементы местами, двигайте оба индекса навстречу друг другу, остановитесь при `left >= right`.

Тикет 5. Чарт отсортирован?
Проверьте, что список цен идёт от меньшей к большей.
Равные соседи допустимы.

- Дано: prices — массив цен.
- Вернуть: true, если каждый элемент не меньше предыдущего. Пустой массив и массив из одного элемента считаются отсортированными.

Примеры:
- task5([1, 3, 3, 8]) -> true
- task5([1, 5, 4]) -> false
- task5([]) -> true

Подсказка: Сравнивайте каждый элемент с предыдущим, начиная с индекса 1. Нашли одну пару в неправильном порядке — можно сразу `return false`.

Тикет 6. Нули в конец
В отчёте показано число скачиваний по дням. Дни без скачиваний равны 0.
Перенесите все нули в конец, порядок остальных чисел сохраните.
Сделайте это в том же массиве.

- Дано: arr — скачивания по дням.
- Вернуть: ничего. Измените сам массив.

Примеры:
- arr = [0, 4, 0, 7, 9], task6(arr) -> arr станет [4, 7, 9, 0, 0]
- arr = [1, 2], task6(arr) -> arr останется [1, 2]

Подсказка: Заведите индекс `pos` — место для следующего ненулевого числа. Копируйте каждый ненулевой элемент в `arr[pos++]`, потом заполните остаток массива нулями.

Тикет 7. Нарастающий итог
В массиве лежит выручка по дням. Для каждого дня отчёт должен показать
общую выручку с первого дня до этого дня включительно.

- Дано: arr — выручка по дням.
- Вернуть: новый массив той же длины. Элемент с индексом i — это сумма arr[0..i].

Примеры:
- task7([1, 2, 3, 4]) -> [1, 3, 6, 10]
- task7([5, -2, 4]) -> [5, 3, 7]
- task7([]) -> []

Подсказка: Заведите одну переменную `sum`. В цикле прибавляйте к ней `arr[i]` и записывайте `sum` в `result[i]`.

Тикет 8. Два альбома на подарочную карту
На подарочной карте точная сумма. Найдите два разных альбома, цены которых в сумме дают её.

- Дано: prices — цены альбомов; amount — сумма на карте.
- Вернуть: массив из двух индексов {i, j}, где i < j и prices[i] + prices[j] == amount.
  Если такой пары нет, верните пустой массив. Если пар несколько, подойдёт любая.

Примеры:
- task8([2, 7, 11, 15], 9) -> [0, 1]
- task8([3, 2, 4], 6) -> [1, 2]
- task8([1, 2], 10) -> []

Подсказка: Два цикла, один внутри другого. Внутренний начинается с `i + 1`, чтобы не брать один альбом дважды.

Тикет 9. Потерянный номер билета
Билеты на концерт пронумерованы 0, 1, 2, ..., n. Один номер в массиве отсутствует,
а сам массив идёт в произвольном порядке.

- Дано: arr из n элементов, все разные, каждый в диапазоне 0..n.
- Вернуть: единственное число из 0..n, которого нет в массиве.

Примеры:
- task9([3, 0, 1]) -> 2
- task9([0, 1]) -> 2
- task9([1]) -> 0

Подсказка: Вы знаете, чему должна равняться сумма всех чисел 0..n. Сравните её с реальной суммой массива.

Тикет 10. Подписи в чарте
На странице чарта для каждой позиции от 1 до n показана подпись:
"FizzBuzz", если позиция делится и на 3, и на 5, "Fizz", если на 3, "Buzz", если на 5,
и сама позиция во всех остальных случаях.

- Дано: n — число позиций (n >= 0).
- Вернуть: одну строку String со всеми подписями через запятую и пробел (", "), или "" при n = 0.

Примеры:
- task10(5) -> "1, 2, Fizz, 4, Buzz"
- task10(15) -> "1, 2, Fizz, 4, Buzz, Fizz, 7, 8, Fizz, Buzz, 11, Fizz, 13, 14, FizzBuzz"
- task10(0) -> ""

Подсказка: Сначала проверьте «делится и на 3, и на 5», иначе победит "Fizz". Используйте `i % 3 == 0`. Собирайте строку через StringBuilder и добавляйте ", " перед каждой подписью, кроме первой.

Тикет 11. Код специального предложения
Промокод действителен, только если он простое число: больше 1 и делится
только на 1 и на само себя.

- Дано: n — код.
- Вернуть: true, если n простое, иначе false.

Примеры:
- task11(7) -> true
- task11(12) -> false
- task11(1) -> false
- task11(2) -> true

Подсказка: Сначала обработайте n < 2. Затем пробуйте делители 2, 3, ... пока `d * d <= n`; если какой-то делит n нацело, число не простое.

Тикет 12. Зеркальное название альбома
Некоторые названия альбомов читаются одинаково слева направо и справа налево, например "level". Проверьте название.
Сравнивайте символы точно, заглавные и строчные буквы считаются разными.

- Дано: s — название; может быть null.
- Вернуть: true, если s — палиндром. Пустая строка и строка из одной буквы — палиндромы. Для null верните false.

Примеры:
- task12("level") -> true
- task12("abca") -> false
- task12("") -> true
- task12(null) -> false

Подсказка: Сначала проверьте null. Затем сравнивайте `s.charAt(left)` и `s.charAt(right)`, пока `left < right`, двигая оба индекса к середине.

Тикет 13. Размер серверной стойки
Стойку можно заказать только размера, который является степенью двойки: 1, 2, 4, 8, 16, ...
Проверьте запрошенный размер.

- Дано: n — запрошенный размер (может быть 0 или отрицательным).
- Вернуть: true, если n равно 1, 2, 4, 8, ... и false в остальных случаях.

Примеры:
- task13(16) -> true
- task13(12) -> false
- task13(1) -> true
- task13(0) -> false
- task13(-8) -> false

Подсказка: Пока n чётное, делите его на 2. В конце степень двойки превратится ровно в 1. Не забудьте, что n <= 0 никогда не степень двойки.

Тикет 14. Сумма бонусных баллов
Бонусные баллы приходят из другой системы как массив Integer. У клиента без данных вместо числа стоит null.
Сам массив тоже может быть null.

- Дано: bonuses — баллы; элементы null означают «неизвестно».
- Вернуть: сумму всех известных баллов. Неизвестные считаются как 0. Для массива null верните 0.

Примеры:
- task14([10, null, 5]) -> 15
- task14([null, null]) -> 0
- task14(null) -> 0

Подсказка: null может быть и сам массив, и любой элемент. Распаковка null бросает NullPointerException.

Тикет 15. Комментарий пустой?
Клиент прислал комментарий. В комментарии есть текст, только если он не null и содержит
хотя бы один символ, не являющийся пробелом.

- Дано: s — комментарий; может быть null.
- Вернуть: true, если в s есть текст, иначе false.

Примеры:
- task15("great album") -> true
- task15("   ") -> false
- task15("") -> false
- task15(null) -> false

Подсказка: Сначала проверьте `s == null`, и только потом вызывайте методы у s. Пробелы в начале и в конце можно убрать через `trim()`.

Тикет 16. Цифра из символа
Серийный номер читают по одному символу. Превратите символ-цифру в её число.

- Дано: c — один символ.
- Вернуть: число 0..9, если c это символ-цифра '0'..'9', иначе -1.

Примеры:
- task16('7') -> 7
- task16('0') -> 0
- task16('a') -> -1

Подсказка: char это число в маскировке. Символы '0'..'9' идут подряд, поэтому `c - '0'` даёт цифру.

Тикет 17. Сумма заказа без переполнения
Общая цена заказа равна price * quantity. Оба числа типа int, но результат
может оказаться больше максимального int (около 2,1 миллиарда).

- Дано: price и quantity — два числа int.
- Вернуть: точное произведение в виде long.

Примеры:
- task17(3, 4) -> 12
- task17(2000000000, 3) -> 6000000000

Подсказка: `price * quantity` считается в int и может переполниться раньше, чем попадёт в long. Сделайте так, чтобы вычисление шло в long.
