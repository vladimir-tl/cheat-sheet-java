Вы работаете в службе поддержки интернет-магазина музыки. Каждый тикет ниже — небольшая рабочая ситуация, и каждый тикет — это один метод, который нужно дописать. Помните: множество хранит каждый элемент только один раз и не имеет постоянного порядка, поэтому {"Bob", "Anna"}, напечатанное в другом порядке, — то же самое множество. Здесь множества записаны в фигурных скобках, а Java печатает их в квадратных: System.out.println(set) выведет [Anna, Bob].

- Дано: параметры, которые получает метод.
- Вернуть: что метод должен вернуть (или как изменить множество).
- Примеры: входные данные и ожидаемые результаты. Запустите их в main, чтобы проверить себя.
---
Тикет 1. Чёрный список
Магазин заводит чёрный список клиентов, которые злоупотребляют поддержкой. Пока в нём никого нет.
Создайте пустой Set<String>. Имена будут добавлять позже, поэтому множество должно позволять добавление.

- Дано: ничего, у метода нет параметров (скобки пустые).
- Вернуть: новое пустое множество.

Пример:
- task1() -> {}

Подсказка: `new HashSet<>()` даёт пустое множество, в которое можно добавлять.

Тикет 2. VIP-клиенты
VIP-клиенты — "Anna", "Bob" и "Eve". Создайте множество с этими тремя именами.

- Дано: ничего, у метода нет параметров (скобки пустые).
- Вернуть: новое множество с тремя именами.

Пример:
- task2() -> {"Anna", "Bob", "Eve"} (в любом порядке)

Подсказка: Создайте пустой `HashSet` и трижды вызовите `add`.

Тикет 3. Подписка на рассылку
Клиент подписывается на рассылку. Добавьте имя в множество подписчиков и сообщите,
новый ли это подписчик. Если имя уже есть, множество не меняется.

- Дано: set — подписчики; name — клиент.
- Вернуть: true, если имя добавлено (новый подписчик), false — если оно уже было в множестве.

Примеры:
- set {"Anna"}, name "Bob" -> true, множество становится {"Anna", "Bob"}
- set {"Anna"}, name "Anna" -> false, множество остаётся {"Anna"}

Подсказка: `add` сам возвращает `true` или `false`: был ли элемент новым?
---
Тикет 4. Клиент заблокирован?
Прежде чем ответить в чате, оператор проверяет чёрный список.

- Дано: set — чёрный список; name — клиент.
- Вернуть: true, если имя есть в множестве, иначе false.

Примеры:
- set {"spammer", "troll"}, name "troll" -> true
- set {"spammer", "troll"}, name "Anna" -> false

Подсказка: `contains(x)` отвечает на вопрос «`x` есть в множестве?».

Тикет 5. Сколько подписчиков?
Маркетинг хочет знать число подписчиков рассылки.

- Дано: set — подписчики.
- Вернуть: количество имён в множестве.

Примеры:
- {"Anna", "Bob"} -> 2
- {} -> 0

Подсказка: Один метод говорит, сколько элементов в множестве.
---
Тикет 6. Отписка
Клиент отписывается от рассылки. Удалите имя из множества.
Если имени в множестве нет, ничего не меняется и ничего не падает.

- Дано: set — подписчики; name — клиент.
- Вернуть: ничего. Измените полученное множество.

Примеры:
- set {"Anna", "Bob"}, name "Bob" -> множество становится {"Anna"}
- set {"Anna"}, name "Tom" -> множество остаётся {"Anna"}

Подсказка: `remove(x)` удаляет `x` из множества.

Тикет 7. Повторяющиеся тикеты
Один клиент может открыть несколько тикетов, поэтому в списке id клиентов есть повторы.
Сделайте из него множество: каждый id клиента по одному разу.

- Дано: numbers — id клиента для каждого тикета.
- Вернуть: новое множество id без повторов.

Примеры:
- [1, 2, 2, 3] -> {1, 2, 3}
- [5, 5, 5] -> {5}

Подсказка: `new HashSet<>(list)` копирует список и убирает повторы.

Тикет 8. Уникальные клиенты за сегодня
Сколько разных клиентов написали сегодня в поддержку? В списке — id клиента для каждого
тикета, и один клиент может встречаться несколько раз.

- Дано: numbers — id клиента для каждого тикета.
- Вернуть: количество разных id.

Примеры:
- [1, 2, 2, 3] -> 3
- [7, 7] -> 1
- [] -> 0

Подсказка: Положите список в множество и спросите у множества `size()`.

Тикет 9. Двойной клик по «Оплатить»
Система подозревает, что клиент нажал «Оплатить» дважды и заказ отправился два раза.
Проверьте список номеров заказов на повторы.

- Дано: numbers — номера заказов.
- Вернуть: true, если хотя бы один номер встречается больше одного раза, иначе false.

Примеры:
- [101, 102, 101] -> true
- [101, 102, 103] -> false

Подсказка: Если есть повторы, множество меньше списка.

Тикет 10. Разные символы в промокоде
Отдел маркетинга хочет знать, сколько разных символов используется в промокоде.
Заглавная и строчная буква — разные символы ('A' — не 'a').

- Дано: text — промокод.
- Вернуть: количество разных символов в нём.

Примеры:
- task10("hello") -> 4 (h, e, l, o)
- task10("aaa") -> 1
- task10("") -> 0

Подсказка: Добавьте каждый символ текста в `Set<Character>`, затем возьмите его `size()`.
